;; CxRealWorld — the real world. Sees CxWell, so it inherits the whole shared
;; ontology. A context representing an invented setting is a sibling under CxWell
;; instead of a context under CxRealWorld, so an exception a fiction states never
;; reaches what holds of the real world.
;;
;; CxUniverse states (disjoint animal vehicle) at the default strength, so a fiction
;; below CxWell may deny it monotonic and hold a term that is both an animal and a
;; vehicle (the Catbus in My Neighbor Totoro): the denial defeats the default
;; declaration there. This context restates
;; the same separation monotonic, so the real world can never hold the overlap.

(genlCx CxRealWorld CxWell)

(set/monotonic (disjoint animal vehicle))
